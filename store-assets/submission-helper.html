Live test and screenshot checklist
  1. In Chrome, open chrome://extensions, turn on Developer mode, choose Load unpacked, and select /Users/kyle/Documents/StayTube. Reload YouTube tabs.
  2. Check the description, date, and comments below the player. Expand the description, load more comments, navigate to another video, and use Back/Forward. Check normal, theater, and full-screen modes.
  3. Check a search result and a playlist row, then scroll to load more. Confirm new rows receive dates and controls. Test Watch Later and playlist removal while signed in.
  4. Copy a captioned transcript and paste it into a text editor. Check timestamps and chapters. Check dark mode and a narrow window.
  5. Capture the actual restored watch page, a listing with publication dates, and playlist tools. Use square corners with no added padding. Exclude private playlist names, account details, and unrelated browser UI. Save PNGs at 1280×800 or 640×400.

6. Submit for review

0 checks completed

  1. Choose Submit for Review once the required dashboard fields are complete.
  2. In the confirmation dialog, keep automatic publishing selected if you want StayTube to go live after approval. Clear that option if you want to publish manually after approval.
  3. Confirm submission. Monitor the item's status and developer email for review questions. If approved with deferred publishing, return to the dashboard and publish it within the displayed deadline.
  4. After it is public, install from the actual store listing in a separate Chrome profile and test one watch page and one dynamically loaded listing. Confirm the public support and policy links work.
If the dashboard blocks submission

Open the indicated tab, fix the missing field, and save. Common missing items are a real screenshot, a reachable privacy-policy URL, an unanswered permission justification, or a data-use certification. For a rejected review, address the specific reason in Google's email and resubmit; do not create another store item.
